# receipts demo

The share pages from [receipts](https://github.com/trivedi-vatsal/receipts) (`share/` on `main`), with made-up data for a fictional engineer.
`data.json` is the source; `data.js` was built from it and six weekly notes by `scripts/build-share.py`.
To refresh after changing the pages on `main`, copy `share/*.html`, `app.js` and `style.css` here.
